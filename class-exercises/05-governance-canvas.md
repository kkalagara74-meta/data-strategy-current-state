# 05 — Governance canvas (FDE exercise draft)

**Autonomy granted:** One model may inspect permitted local sources and decide which issue-level next action to take: more evidence, request human input, or provisional finding. Discovery can register an inventory of issues. A run budget controls investigation depth, not the product's business scope.

**Human authority:** A consultant supplies missing information, accepts, requests revision, or rejects a draft finding. Their decision is logged per issue. Accepting a draft is **not** authorization to release a client-facing report. No external actions are permitted.

**Evidence:** Every documented observation must cite a source already read; no assumed source counts as corroboration. Hypothesized or stakeholder-reported causes are not called verified root causes. Uncertainty, contradictions, and uninvestigated issues remain visible.

**Evaluation and accountability:** Maintain issue IDs, action and outcome log, run ID, source locators, finding evidence, and review records. This is a local training artifact, not a production compliance log.

**Stop conditions:** Invalid references, inadequate information, unsupported claims, turn limit, or human-clarification need. A single pending issue should not stop work on other issues.
