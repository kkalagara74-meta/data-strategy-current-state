# 01 — Engagement brief (FDE exercise draft)

**Customer/use:** A data-strategy consultant beginning a Current State Analysis of a client organization. Inputs vary across clients; the problem is to turn interviews and documents into defensible findings about what is and isn't working and why it affects business decisions.

**Current workflow:** Read business context, interviews and technical material; identify issues, compare accounts, investigate likely explanations, record gaps and prepare draft diagnostic slides for partner review. Risks include unsupported causal claims and losing the link to original input.

**Proposed narrow capstone:** One agent identifies **multiple** issues, investigates a bounded set one by one, chooses whether to gather more evidence / request clarification / submit each draft, and prepares **one consolidated draft Current State Diagnostics**. Human reviews each finding.

**Success criteria:** (1) issue inventory contains more than one distinct, quoted issue when present; (2) pending issue does not block other issues; (3) each submitted draft has quote, source locator, business relevance status, and cause uncertainty; (4) action log shows distinct next actions; (5) consolidated output groups findings using People/Process/Technology/Data; (6) same code loads a second engagement.

**Baseline / target:** Baseline time and analytical quality **not measured**. Target for class demo: pass scripted contract tests, then have a human review sample outputs and compare them with frozen evaluation expectations. Quantitative time-saved/ROI cannot yet be substantiated.

**Constraints:** No write to client systems, no autonomous outreach, no final approval; class API cost budget; use anonymized/synthetic records. Do not confuse test data with real observations. Original test brief may be confidential.

**Out of scope:** Entire strategy lifecycle, full Decision & Metric Map creation, target architecture, recommendations, roadmap, unapproved source distribution, production integrations, multiple agents.

**Sign-off needed:** Instructor approval if substituting official class scenario; consultant acceptance of evaluation labels before claiming analytical accuracy.
