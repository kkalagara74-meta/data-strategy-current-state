# FDE course exercises versus the Data Strategy capstone

These **six class exercise documents are training artifacts**, not part of the consulting methodology's interim work or client deliverables.

| Official FDE exercise | Capstone adaptation |
|---|---|
| 01 Engagement brief | Current State Analysis business problem, bounded investigation, draft diagnostic success checks. |
| 02 Integration map | Input normalization, local read-only tools, agent decision loop, saved issue/action state, individual human review. |
| 03 Evaluation contract | Candidate cases, offline multi-issue tests, required live and human judgment. |
| 04 Security review | Source text untrusted, scope-limited local access, prompt injection risk, confidential documents. |
| 05 Governance canvas | Human decisions, no client release authorization, per-issue status. |
| 06 Go-live and handover | Demo instructions, run budget, failure and manual handling, outstanding validation. |

The official lab scenario is **Calder & Rowe**, not this capstone's Alchemy fixture. Complete official labs as directed; instructor approval is needed to substitute the capstone.
