- `Alchemy_Project_Challenge.docx`: original project brief supplied as practice material; its marking may restrict sharing.
- `Alchemy_Stakeholder_Responses.xlsx`: original synthetic respondent workbook, unchanged.
- `sources_all.jsonl`: **71** normalized evidence records (11 brief paragraphs + 60 worksheet response cells) with IDs and locators. Used by default.
- `sources_for_class.jsonl`: **40** selected evidence records (11 brief paragraphs + 29 stakeholder responses) to reduce exploratory cost. **Curated subset is not exhaustive**.
- `source_manifest.json`: data-file attribution/selection manifest.

Source content remains unmodified. Source locators such as `Responses!F2` correspond to the original Excel cell. The workbook's guidance and the derived summary are not separate independent evidence. The separate question-bank CSV is not included as evidence because it contains questions/guidance rather than responses. For a new engagement, normalize authorized inputs into the same schema; automatic Office ingestion is not implemented.
